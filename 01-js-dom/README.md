# カード一覧の表示・非表示

## 目的

HTML、CSS、JavaScriptを使って、カード一覧を作成する。

画面の見た目を確認しながら、HTMLで構造を作り、CSSでレイアウトを整え、JavaScriptで表示状態を操作する。

## 作成するもの

- 架空のカードを3枚作る
- `placehold.jp`のダミー画像をカードごとに設定する
- PC画面ではカードを横並びにする
- スマートフォンではカードを縦並びにする
- ボタン操作でカード全体の表示・非表示を切り替える

## 作業手順

1. 架空のカード3枚をHTMLで作る
2. それぞれのカードにダミー画像を設定する
3. CSSでカードの幅、余白、背景、角丸などを整える
4. CSS GridまたはFlexboxを使ってカードを横並びにする
5. メディアクエリを使って、スマートフォンでは縦並びにする
6. JavaScriptで表示・非表示を切り替えるボタンを追加する
7. PC表示とスマートフォン表示の両方を確認する
8. ボタン操作が正しく動くことを確認する

## 完成条件

- [ ] 架空のカードが3枚表示されている
- [ ] 3枚のカードにそれぞれ画像が設定されている
- [ ] PC画面ではカードが横並びになっている
- [ ] スマートフォンではカードが縦並びになっている
- [ ] カードの余白や画像サイズが大きく崩れていない
- [ ] ボタンでカードを非表示にできる
- [ ] もう一度ボタンを押すとカードを表示できる
- [ ] ブラウザの開発者ツールにエラーが出ていない

## 確認する画面幅

- PC表示
- タブレット表示
- スマートフォン表示

## 学ぶこと

- HTMLの要素構造
- class名の付け方
- CSS GridまたはFlexbox
- メディアクエリ
- JavaScriptによるHTML要素の取得
- クリックイベント
- 表示・非表示の切り替え
