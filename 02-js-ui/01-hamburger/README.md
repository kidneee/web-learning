# UIの開閉と切り替え

## 目的

JavaScriptを使って、画面上のUIを操作する。

今回は、ユーザーの操作に応じて表示内容や見た目が変わるUIを作り、HTML・CSS・JavaScriptの役割分担を理解する。

## 作成するもの

### 1. ハンバーガーメニュー

- ボタンをクリックするとメニューが開く
- もう一度クリックするとメニューが閉じる
- メニューの表示状態に応じて、ボタンの見た目を変える

### 2. タブ切り替え

- 複数のタブを作る
- タブをクリックすると対応する内容が表示される
- 選択中のタブに見た目の変化を付ける
- 一度に表示する内容は1つにする

## 作業手順

1. ハンバーガーメニューのHTMLを作る
2. CSSでメニューの通常状態と開いた状態を作る
3. JavaScriptでメニューの開閉を切り替える
4. ボタンの状態とメニューの表示状態が一致することを確認する
5. タブとタブに対応するコンテンツをHTMLで作る
6. CSSで選択中のタブを分かるようにする
7. JavaScriptでクリックしたタブに対応する内容を表示する
8. 他のタブの内容が非表示になることを確認する
9. PCとスマートフォンの両方で表示を確認する

## 完成条件

### ハンバーガーメニュー

- [ ] メニューボタンが表示されている
- [ ] ボタンをクリックするとメニューが表示される
- [ ] もう一度クリックするとメニューが非表示になる
- [ ] メニューの表示状態とボタンの見た目が一致している
- [ ] ボタンを連続してクリックしても正常に動作する

### タブ切り替え

- [ ] 複数のタブが表示されている
- [ ] 初期状態で1つ目の内容が表示されている
- [ ] タブをクリックすると対応する内容が表示される
- [ ] 選択中のタブが見た目で分かる
- [ ] 表示される内容が常に1つになる
- [ ] タブを順番にクリックしても正常に切り替わる

### 共通

- [ ] ブラウザの開発者ツールにエラーが出ていない
- [ ] PC表示で操作できる
- [ ] スマートフォン表示で操作できる
- [ ] JavaScriptを変更した内容をGitにコミットしている

## 学ぶこと

- クリックイベント
- classの追加と削除
- classの切り替え
- 条件分岐
- 現在の表示状態の管理
- 複数の要素から対象を判別する方法
- UIの状態と見た目を連動させる方法
- `aria-expanded`や`aria-selected`などのアクセシビリティ属性

## 今回の考え方

JavaScriptで直接すべての見た目を変更するのではなく、

- HTML：ボタン、メニュー、タブ、コンテンツを用意する
- CSS：通常状態と変更後の見た目を用意する
- JavaScript：クリックに応じて状態を切り替える

という役割分担で作る。

## 今回はやらないこと

- React化しない
- WordPress化しない
- APIを使わない
- 複雑なアニメーションを作らない
- 実案件のHTMLや画像を使わない
- 最初から完璧なデザインを目指さない

まずはハンバーガーメニューを完成させ、その後にタブ切り替えへ進む。

## 学習の進め方

1. 画面上の見た目をHTMLとCSSで作る
2. クリックしたときに何が変わるかを決める
3. JavaScriptで一つの動きだけ実装する
4. ブラウザで動作を確認する
5. 動いたらGitにコミットする
6. 分からない部分は、コード全体ではなく該当する動きについて質問する
